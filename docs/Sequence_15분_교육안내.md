# Sequence 15분 교육 안내

> **이 문서의 성격 — 제안(proposed)입니다.**
> 아래 순서와 화면 문구는 저장소의 실제 화면·기능에서 뽑았습니다. 반면 **교육 일정·강사·차수는
> 아직 정해진 것이 없습니다** — `⬜` 칸은 담당자가 채웁니다.

**대상:** 처음 쓰는 사람 · **시간:** 15분 · **준비물:** 사내망에 연결된 PC(크롬 또는 엣지)
**끝나면 할 수 있는 것:** 본부 샘플 공정표를 열어 → 일정을 바꾸고 → 진척을 넣고 → PDF로 뽑기

교육 일시 ⬜ · 장소 ⬜ · 진행자 ⬜ (배포 시 기입)

---

## 0–3분 · 접속하고 들어가기

1. 브라우저에서 접속 주소를 엽니다 → `docs/Sequence_접속_및_사용자등록_안내.md` §1
2. 처음이면 **사용자 등록**(역할 = 사용자, 본부 = 본인 소속, 아이디 = 전화번호) → §2
3. 로그인 → **프로젝트 선택 화면**에서 본인 본부의 **`[샘플] …`** 프로젝트에 입장

- [ ] **확인:** 화면 왼쪽에 세로 모듈 목록, 가운데에 막대가 있는 도면이 보인다.
- **이 화면이 안 나오면:** 접속 주소·포트가 맞는지, 사내망에 붙어 있는지 확인하세요.
  그래도 안 되면 상단 **🛟 문의**.

## 3–8분 · 일정 바꾸기 (공정관리)

1. 왼쪽 모듈 목록에서 **📅 공정관리**를 누릅니다.
2. 도면의 **막대를 좌우로 드래그** → 일정이 바뀝니다.
3. 막대를 클릭하면 양 끝에 **핸들**이 생깁니다 → 끌어서 **기간** 조절.
4. 막대 끝의 **●** 를 다른 공정의 앞/뒤로 끌면 **선후행 화살표**가 생깁니다.
5. 막대 아래 **‘○일’ 글자를 더블클릭** → 숫자를 넣으면 기간이 바뀝니다.

- [ ] **확인:** 막대를 옮기면 위쪽/아래쪽 **총 공기**와 **주공정(빨간 막대)** 이 따라 바뀐다.
- **막대가 안 잡히면:** 왼쪽 위 상태가 **🔒 조회 전용**인지 보세요 — 조회 전용이면 편집이 막힙니다
  (담당 관리자에게 편집 권한을 요청).
- **화면이 끌려다니면:** 캔버스 도구가 **이동 모드(H)** 입니다. **V** 또는 **Esc** 로 편집 모드 복귀.

## 8–12분 · 진척 넣고 대시보드에서 확인

1. 왼쪽 모듈 목록에서 **📈 진척·실적**.
2. 공정별 **진척률(%)**, **실적 착수일·완료일**, **담당자**를 입력합니다.
3. 왼쪽 모듈 목록 맨 위 **🏠 대시보드** 로 이동해 **계획 대비 실적**을 봅니다.

- [ ] **확인:** 대시보드에 진척이 반영된 수치가 보인다.
- **숫자가 안 바뀌면:** 진척·실적 화면으로 돌아가 입력 칸에서 **Tab 또는 다른 칸 클릭**으로
  입력을 확정했는지 확인하세요.

## 12–15분 · 출력하고 저장하기

1. 다시 **📅 공정관리** → 상단 오른쪽 **도면 출력**.
2. **용지(A3)** · **방향(가로)** · **형식(PDF)** 을 고르고 **미리보기 만들기**로 확인.
3. **사전 점검** 문구(여백·잘림)를 읽고 문제가 없으면 출력.
4. 창을 닫고 상단 **저장**(또는 **Ctrl+S**) → **.json 파일**로 저장합니다.

- [ ] **확인:** PDF가 열리고, 상단의 **‘● 미저장’** 표시가 사라졌다.
- **‘여백으로 남습니다’ 경고가 뜨면:** 같은 창의 **[여백 없이 시트에 맞추기]** 를 누르세요.
- **꼭 기억할 것:** **자동 저장이 없습니다.** 작업을 마치면 반드시 **저장**하세요.
  (브라우저에 마지막 작업이 임시 복원되지만, 그건 캐시일 뿐 보관 수단이 아닙니다.)
