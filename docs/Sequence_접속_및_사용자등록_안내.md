# Sequence 접속 및 사용자 등록 안내

전사 공통 **토목 공정표(공정 스케줄) 협업 프로그램 “Sequence”** 사용 안내입니다.
아래 순서대로 **접속 → 사용자 등록 → 로그인** 하시면 됩니다.

---

## 1. 접속 방법

> **접속 주소 :** `http://10.12.29.180:4020/`

- **사내망(LAN)** 에 연결된 상태에서 위 주소로 접속합니다.
- 권장 브라우저: **크롬(Chrome)** 또는 **엣지(Edge)** 최신 버전.
- PC·노트북·태블릿 모두 같은 주소로 접속 가능합니다.
- 접속이 안 되면 ① 사내망(Wi-Fi/유선) 연결 확인, ② 주소·포트(`:4020`) 정확히 입력했는지 확인하세요.

---

## 2. 사용자 등록 (최초 1회)

1. 접속 주소를 열면 **로그인 화면**이 나옵니다.
2. 로그인 버튼 아래 **`사용자 등록`** 을 클릭합니다.
3. **역할**을 선택합니다.
   | 역할 | 설명 | 사용 시점 |
   |---|---|---|
   | **사용자** | 배정된 프로젝트에 참여해 공정표를 함께 편집 | **등록 즉시** 로그인 가능 |
   | **관리자** | 본부 프로젝트를 생성·관리 | **개발자 승인 후** 로그인 가능 |
4. **본부**를 선택합니다. (아래 [본부 목록](#5-본부-목록) 참고 — 본인 소속 본부 선택)
5. **이름**을 입력합니다.
6. **전화번호(= 아이디)** 를 입력합니다. → `010` 으로 시작하는 **숫자 11자리**, 하이픈(-) 없이. (예: `01012345678`)
7. **비밀번호**를 설정합니다. → **8~12자 · 영문·숫자·특수기호(!@#$%^&\*) 중 2종 이상 조합** ([정책 상세](#4-비밀번호-정책))
8. **`등록`** 을 누릅니다.
   - **사용자** → “사용자 등록이 완료되었습니다” 안내 후 **바로 로그인** 가능.
   - **관리자** → “관리자 등록 신청이 접수되었습니다(승인 대기)” 안내. **관리자 승인 후** 로그인 가능.

---

## 3. 로그인

- **아이디** = 등록한 **전화번호** (예: `01012345678`)
- **비밀번호** = 등록 시 설정한 비밀번호

로그인하면 **프로젝트 선택 화면**이 나옵니다. 본인 본부의 프로젝트가 표시되며, 배정된 프로젝트에 입장해 공정표를 편집·실시간 협업할 수 있습니다.
> 일부 프로젝트는 **접속코드**가 걸려 있을 수 있습니다. 이 경우 담당 관리자에게 접속코드를 받아 입장 시 입력하세요.

---

## 4. 비밀번호 정책

- **길이:** 8 ~ 12자
- **사용 가능 문자:** 영문(A–Z, a–z) · 숫자(0–9) · 특수기호(`! @ # $ % ^ & *`)
- **조합:** 위 3종(영문·숫자·특수기호) 중 **2종 이상** 포함
- 예시: `sequence1`, `Hydro2026`, `saman!2026`

> 로그인 **5회 실패** 시 계정이 잠깁니다. 이때는 로그인 화면의 **“비밀번호 초기화 요청”** 으로 관리자에게 요청하면 새 비밀번호를 안내받을 수 있습니다.

## 6. 자주 묻는 질문

- **Q. 접속이 안 돼요.** → 사내망에 연결되어 있는지, 주소와 포트(`:4020`)가 정확한지 확인하세요.
- **Q. 관리자로 등록했는데 로그인이 안 돼요.** → 관리자는 **승인 후** 로그인됩니다. 잠시 후 다시 시도하거나 담당자에게 문의하세요.
- **Q. 비밀번호를 잊었어요 / 잠겼어요.** → 로그인 화면의 **“비밀번호 초기화 요청”** 을 이용하세요.
- **Q. 아이디가 뭔가요?** → 등록 시 입력한 **전화번호**(숫자 11자리)가 아이디입니다.
