# 일정 취입 연결 검토 및 수정 계획

2026-09-10 읽기 전용 실행 재현에서 다음 세 결함을 확인했다. 기존 일정 취입 스모크 238개는 통과했으나 아래 경계 사례는 누락돼 있었다.

1. 같은 ID의 공정을 다른 공종으로 재취입해도 기존 공종에 남는다. 신규 목적 공종은 계획에도 누락된다. 계획의 변경 항목과 공종 생성 목록을 보완하고, 갱신 시 categoryId를 반영한다.
2. 같은 양 끝/관계 유형의 선후행 연결은 재취입 시 지연일 변경을 무시한다. 기존 링크 ID를 보존하면서 지연일을 갱신한다. 동일 내용 재취입은 연결을 추가하지 않는다.
3. 종료일이 시작일 하루 전인 행은 포함일수 계산 결과 0이 되어 마일스톤으로 취입된다. 명시한 종료일이 시작일보다 앞서면 오류로 판정하되, 종료일 없이 기간 0을 명시한 정상 마일스톤은 유지한다.

회귀테스트를 먼저 추가해 실패를 확인하고 위 범위만 수정한다. 재취입 후 공종·지연일, 같은 내용 재취입의 멱등성, 한 번의 실행 취소, 역전 날짜와 정상 마일스톤을 검증한다. CRDT 및 공통 스모크와 TypeScript 검사로 관련 연결을 확인한다. 다른 작업자의 변경은 보존한다.
