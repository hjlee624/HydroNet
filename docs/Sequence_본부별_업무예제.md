# Sequence 본부별 업무 예제

> **이 문서의 성격 — 제안(proposed)입니다.**
> 아래 11개 예제는 저장소에 **이미 들어 있는 자산**(본부 목록 · 본부별 샘플 프로젝트 · 실제로 동작하는
> 모듈)에서만 끌어왔습니다. 반면 **사람·일정·소요시간 숫자는 아직 아무것도 측정되지 않았습니다.**
> `⬜` 로 표시된 칸은 **담당자가 직접 채워야 하는 자리**이며, 채우기 전에는 어떤 효과도 주장하지 않습니다.

## 출처 (모두 저장소에서 확인 가능)

| 내용 | 출처 파일 |
|---|---|
| 본부 11개(이름·순서) | `client/src/data/divisions.ts` |
| 본부별 샘플 프로젝트(시설물 · 도면 단계 · 프로젝트명) | `client/scripts/gen-sample-projects.ts` → `server/seed-samples/<본부키>.json` |
| 모듈(공정관리 · 진척·실적 · 보고서 등)의 실제 동작 여부 | `client/src/data/modules.ts` 의 `status` |
| 접속 · 등록 · 비밀번호 | `docs/Sequence_접속_및_사용자등록_안내.md` |

서버가 처음 뜰 때 위 샘플 프로젝트가 본부마다 하나씩 자동으로 심어집니다. **새 데이터를 만들 필요 없이
본인 본부의 `[샘플] …` 프로젝트를 열어 그대로 따라 해 보면 됩니다.**

---

## 공통 준비 (모든 본부 동일)

1. `docs/Sequence_접속_및_사용자등록_안내.md` 대로 접속 · 등록 · 로그인.
2. 프로젝트 선택 화면에서 본인 본부의 **`[샘플] …` 프로젝트**에 입장.
3. 처음이면 `docs/Sequence_15분_교육안내.md` 를 한 번 따라 하고 오세요.
4. 막히면 상단 **🛟 문의 → 📋 진단 정보 복사** 후 본부 담당자에게 붙여넣어 전달.

> **소요시간 칸을 채우는 법** — 같은 업무를 **① 지금 쓰는 방식(엑셀 등)** 으로 한 번,
> **② Sequence** 로 한 번 해 보고, 각각 **시작·종료 시각을 적어** 분 단위로 기록합니다.
> 개인의 속도를 평가하려는 것이 아니라 **도구가 걸리는 자리**를 찾기 위한 것입니다
> (원칙은 `docs/Sequence_지원체계_및_도입효과_측정.md` 참고).
